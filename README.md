# Tayara.tn UX/UI Design

## 📌 Project Overview

This project focuses on the **UX/UI analysis and improvement of the Tayara.tn web platform**.

The objective is to study the existing interface, identify usability issues through user feedback, and propose improvements to make the platform more organized, accessible, and user-friendly.

## 🔎 Research

The project begins with an analysis of the Tayara.tn platform and its usage, followed by user feedback collected through a questionnaire.

The research identified several areas for improvement, including:

* Search functionality and autocorrection
* Data validation for fields such as price and brands
* Account creation and login options
* Message notifications
* Differences between web and mobile interfaces
* Organization and usability of the interface

## 💡 Ideation

Based on the research findings, several solutions were proposed:

* Account creation using **Facebook, email, or phone number**
* Notifications when a new message is received
* Separate interfaces for:

  * 🛒 Buying
  * 🏷️ Selling
  * 💼 Job requests
* A button allowing users to quickly return to the top of the page

## 🎨 Design

The project follows a UX/UI design process focused on:

* User research
* Problem identification
* User feedback analysis
* Ideation
* Interface improvement
* Usability and accessibility

## 🎯 Objective

The main objective is to improve the overall user experience of Tayara.tn by addressing identified usability problems and proposing a clearer and more efficient interface.

## 📊 Key Findings

The questionnaire indicated that users generally found the interface usable, while also identifying issues related to **organization, missing options, navigation, and functionality**.
